# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you discover a security or numerical-integrity issue (such as incorrect drawdown boundary calculation, CSV parsing edge cases, or CLI argument handling flaws), please open a GitHub Security Advisory or submit an issue with steps to reproduce.

We review all reports promptly and release patched versions with regression tests.
